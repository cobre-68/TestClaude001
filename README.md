# Zentrale

Persönliche Organizer-App für Android – Termine, Erinnerungen und Sprachsteuerung, **privat und geschäftlich getrennt**.

## Funktionen (v0.1)
- Eigener Kalender mit den Bereichen **Privat** und **Geschäftlich**, Filter oben
- 🎙 **Spracheingabe** in natürlichem Deutsch, z. B.
  - „Morgen um 10 Uhr Zahnarzt“
  - „Freitag 14:30 Meeting mit Rikke geschäftlich“
  - „Weck mich morgen um 6:45“
  - „In 20 Minuten Pizza aus dem Ofen“
- 🔊 Tagesübersicht vorlesen, gesprochene Bestätigungen
- 🔔 Erinnerungen mit Ton, Vibration und Benachrichtigung
- Offline-fähig, auf dem Startbildschirm installierbar

## Installation auf Android
1. Die GitHub-Pages-Adresse in Chrome öffnen
2. Menü ⋮ → **Zum Startbildschirm hinzufügen** / **App installieren**

## Entwicklung
Kein Build nötig – `index.html` direkt öffnen oder lokal serven:
```
python3 -m http.server 8000
```
